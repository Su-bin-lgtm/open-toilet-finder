# 📋 시스템 요구사항 정의서 (System Requirements Specification)

본 문서는 **개방화장실 실시간 정보 공유 및 내비게이션 플랫폼**의 기능 및 비기능 요구사항을 정의합니다. (SW중심대학 산학협력 프로젝트 계획서 기준)

---

## 🎯 1. 개발 목적 및 핵심 철학

1. **골든타임 확보**: 급박한 상황을 고려하여 **앱 실행 후 3단계 이내에 화장실 상세 정보 및 경로에 도달**하도록 설계합니다.
2. **사전 헛걸음 방지**: 방문 전에 개방 여부, 도어락 비밀번호 유무, 이용 가능 시간을 미리 파악할 수 있도록 정보를 통합 제공합니다.
3. **사회적 약자 배려**: 영유아 동반 부모(기저귀 교환대), 휠체어 이용자(장애인 화장실/경사로), 과민성 대장 증후군 환자 등 사용자 유형별 맞춤 필터를 지원합니다.
4. **집단 지성(Crowdsourcing)**: 공공데이터의 느린 업데이트 주기를 극복하기 위해 사용자 현장 제보로 실시간 상태(휴지 유무, 위생, 도어락 번호)를 최신화합니다.

---

## 👥 2. 사용자 페르소나 및 요구사항 매핑

| 페르소나 | 겪는 어려움 | 필수 제공 정보 / 기능 |
| :--- | :--- | :--- |
| **초행길 / 급한 이용자** | 주변 지리를 모르고 길을 헤맴 | 현재 위치 기준 최단거리 화장실 탐색, 외부 내비 연동 |
| **영유아 동반 보호자** | 도착 후 기저귀 교환대가 없어 낭패 | 기저귀 교환대 설치 여부 필터링 |
| **휠체어 이용자** | 턱이 있거나 장애인 화장실이 없음 | 장애인 화장실 유무, 층수 및 엘리베이터 여부 |
| **과민성 대장 증후군 환자** | 잠겨있거나 휴지가 없어 이용 불가 | 실시간 개방 여부, 도어락 번호, 휴지 비치 제보 |

## ⚙️ 3. 상세 기능 요구사항

### F01. 현재 위치 기반 화장실 탐색
* GPS를 기반으로 반경(기본 500m, 최대 2km) 내 화장실을 지도 및 리스트로 표출합니다.
* 화장실 마커는 개방 여부(초록: 개방 / 빨강: 닫힘)에 따라 시각적으로 구분합니다.

### F02. 화장실 상세 정보 조회
* 주소, 개방 시간, 남녀 분리 여부, 변기 수, 비상벨/CCTV 유무 정보를 제공합니다.
* 사용자의 현재 위치로부터의 직선 거리 및 도보 예상 시간을 표출합니다.

### F03. 개방 여부 및 운영 시간 판별
* 24시간 개방 화장실은 상시 "이용 가능"으로 표시합니다.
* 특정 시간제 화장실은 현재 시각과 비교하여 "개방 중", "곧 마감(1시간 전)", "영업 종료" 상태를 표시합니다.

### F04. 도어락 및 출입 정보 제공
* 상가 건물 등 도어락이 설치된 화장실의 비밀번호 힌트 또는 출입 방법(예: 영수증 하단 기재)을 공유합니다.
* 관리 주체(건물주 등)의 비공개 요청 시 즉시 삭제 가능한 관리 정책을 수립합니다.

### F05. 실시간 상태 제보 (Crowdsourcing)
* 사용자가 원클릭으로 현장 상태를 제보할 수 있습니다:
  * 휴지 비치 여부: 있음 / 없음
  * 위생 상태: 청결함 / 보통 / 청소 필요
  * 출입문 개방 상태: 열려있음 / 잠겨있음
* 제보 시각을 함께 표시하여 데이터 신뢰도를 높입니다.

### F06. 맞춤형 편의시설 필터링
* 다중 조건 선택 지원:
  * `장애인 화장실 구비`
  * `기저귀 교환대 구비`
  * `휴지 비치 확인됨`
  * `현재 개방 중`

### F07. 신규 개방화장실 등록
* 공공데이터에 등록되어 있지 않은 카페, 지하철역, 개방 상가 화장실을 사용자가 직접 위치와 함께 등록할 수 있습니다.

### F08. 정보 오류 신고
* 폐쇄된 화장실, 철거, 위치 오표기, 비밀번호 변경에 대해 신고할 수 있으며, 다수의 신고 접수 시 관리자 검증 상태로 전환합니다.

### F09. 외부 지도 앱(길찾기) 연동
* 자체 내비게이션 엔진 개발 대신 안정적인 상용 지도 앱의 URL Scheme(Deep Link)을 호출합니다:
  * 카카오맵 길찾기
  * 네이버 지도 길찾기
  * TMAP 길찾기

### F10. 생성형 AI 보조 기능 (계획서 반영)
* 사용자가 자유 텍스트로 남긴 제보 코멘트(예: "두 번째 칸 변기 막혔고 휴지는 입구에만 있어요")를 요약하고 주요 태그로 자동 분류하는 보조 수단으로 활용합니다.

## 🔒 4. 비기능 및 보안 요구사항

1. **개인정보 보호**:
   * 사용자 위치 정보는 서버에 저장하지 않으며, 주변 검색 쿼리 파라미터로만 일회성 활용합니다.
   * 사용자 제보는 로그인 없이도 비식별(익명 식별자) 기반으로 참여할 수 있도록 하여 진입 장벽을 낮춥니다.
2. **데이터 신뢰도 관리**:
   * 최신 제보 우선 원칙을 적용하며, 제보가 오래된 경우(예: 7일 경과) "미확인" 상태로 자동 전환합니다.
3. **응답 속도**:
   * 주변 화장실 검색 API는 반경 1km 이내 기준 500ms 이내에 응답해야 합니다.
