# 📊 Data Directory (공공데이터 수집 및 전처리)

이 디렉토리는 전국 개방화장실 공공데이터의 원본 수집, 정제 및 데이터베이스 적재 과정을 관리합니다.

---

## 📂 폴더 구조

* **`raw/`**: 공공데이터 포털에서 다운로드받은 원본 파일 (`.csv`, `.json`)
* **`processed/`**: 백엔드 MySQL 데이터베이스에 적재하기 위해 결측치 처리 및 좌표 변환을 거친 정제 파일

---

## 🌐 공공데이터 출처 안내

* **데이터셋 명**: 행정안전부 - 전국 개방화장실 표준데이터
* **다운로드 URL**: [공공데이터포털 전국 개방화장실 표준데이터](https://www.data.go.kr/data/15012892/standard.do)
* **포맷**: CSV / JSON

---

## 📋 핵심 수집 항목 (컬럼 매핑)

| 공공데이터 컬럼명 | DB 엔티티 필드명 | 데이터 타입 | 설명 |
| :--- | :--- | :--- | :--- |
| `화장실명` | `name` | VARCHAR(100) | 화장실 명칭 |
| `소재지도로명주소` / `지번주소` | `address` | VARCHAR(255) | 기본 주소 |
| `WGS84위도` | `latitude` | DECIMAL(10, 7) | 위도 (GPS) |
| `WGS84경도` | `longitude` | DECIMAL(10, 7) | 경도 (GPS) |
| `개방시간상세` / `개방시간` | `open_time_info` | VARCHAR(150) | 운영 시간 ("24시간", "09:00~18:00") |
| `남녀공용화장실여부` | `is_unisex` | BOOLEAN | 남녀 공용 여부 (Y/N -> true/false) |
| `남성용-장애인용대변기수` | `male_disabled_toilet_count` | INT | 남성 장애인 화장실 수 |
| `여성용-장애인용대변기수` | `female_disabled_toilet_count` | INT | 여성 장애인 화장실 수 |
| `기저귀교환대유무` | `has_diaper_table` | BOOLEAN | 기저귀 교환대 설치 여부 |
| `관리기관명` | `management_agency` | VARCHAR(100) | 관리 지자체 또는 공공기관명 |
| `전화번호` | `phone_number` | VARCHAR(30) | 관리기관 연락처 |

---

## 🔄 전처리 및 정제 규칙

1. **결측치(Missing Values) 처리**:
   * 위도/경도가 없거나 유효 범위(한국 기준 위도 33~39, 경도 124~132)를 벗어난 데이터는 제외합니다.
   * 주소가 비어있는 경우 정제 과정에서 지오코딩 또는 필터링합니다.
2. **24시간 개방 여부 불리언 정제**:
   * 개방시간 문자열에 `24시간`, `상시`, `연중무휴`가 포함된 경우 `is_open_24h = true`로 파싱합니다.
3. **인코딩 표준화**:
   * 공공데이터 CSV는 보통 `CP949(EUC-KR)`로 제공되므로, 적재 전 반드시 `UTF-8`로 변환합니다.
